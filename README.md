# HomeBound

HomeBound is a front-end demo app for students looking to find fellow Thapar students traveling to the same hometown around the same time.

## Features

- Student dashboard with travel stats and upcoming plans
- Discovery page for matching travel routes
- Plan creation and editing flow
- Connection requests and messaging mockups
- Profile and settings screens
- Light/dark theme toggle
- Demo-only local state using browser storage

## Project structure

- `index.html` – app entry point
- `styles.css` – all styling and theme definitions
- `app.js` – app logic, demo data, rendering, and interactions

## Run locally

Clone the repository:

```bash
git clone https://github.com/agrimatiwari/HomeBound.git
cd HomeBound
```

Then open `index.html` in your browser to use the app.

## Notes

- This is a prototype/demo application.
- Data is stored in `localStorage` in the browser.
- No backend, authentication, or real database is connected.
